# 🏓 פינג פונג תלת ממדי

משחק פינג פונג (טניס שולחן) תלת ממדי שרץ בדפדפן, בקובץ HTML אחד ללא שום תלות חיצונית.
הגרפיקה נכתבה ב-WebGL גולמי (שיידרים, מטריצות ומשולשים) — בלי Three.js ובלי ספריות.

## איך משחקים

| פעולה | שליטה |
|---|---|
| הזזת המחבט | עכבר (או מקשי חצים / WASD) |
| הגשה / התחלה | רווח או קליק |
| משחק חדש | `R` |
| רמת קושי | `1` קל · `2` בינוני · `3` קשה |
| צליל | `M` |

המשחק עד 11 נקודות, בהפרש של 2. ההגשה מתחלפת כל שתי נקודות (ומכל נקודה מ-10:10).
הכללים כמו בטניס שולחן: כדור שנופל פעמיים באותו צד, יוצא מהשולחן או נתקע ברשת — נקודה ליריב.

## הרצה מקומית

פשוט לפתוח את `index.html` בדפדפן. אין שלב בנייה ואין התקנות.

## פרסום ב-GitHub Pages

בריפו ב-GitHub: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
כמה שניות אחר כך המשחק יהיה זמין בכתובת `https://<user>.github.io/<repo>/`.

## מבנה

הכול נמצא ב-[index.html](index.html):

- **מנוע רנדור** — מטריצות 4x4, שיידר Phong פשוט, ומחוללי מש (תיבה, כדור, גליל).
- **פיזיקה** — כבידה, קפיצות מהשולחן עם ריסון, התנגשות רשת, ופגיעות מחבט.
- **חישוב מכה** — כל מכה מחושבת כך שהכדור *ינחת* בנקודת יעד בצד היריב, תוך התאמת גובה הקשת כדי לעבור מעל הרשת.
- **יריב ממוחשב** — מדמה קדימה את מסלול הכדור כדי לחזות היכן יגיע, ונע לשם במהירות ובדיוק שנקבעים לפי רמת הקושי.
